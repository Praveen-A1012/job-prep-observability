# 📊 Job Prep Observability Dashboard

A beginner-friendly Data Science + Monitoring project.

## Stack
- FastAPI
- Prometheus
- Grafana
- SQLite
- Docker

## Features
- Tracks daily study metrics
- Real-time dashboards
- Correlation (sleep vs productivity)
- Moving averages
- Forecast metrics

## Run
docker compose up --build

App: http://localhost:8000  
Prometheus: http://localhost:9090  
Grafana: http://localhost:3000
